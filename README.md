# わくわく さんすう

小学1年生向けの、10問ずつ遊べる計算ゲームです。HTML・CSS・JavaScriptだけで動作し、外部サービス、外部フォント、ライブラリ、データベースを使いません。

## 作成したファイル

- `index.html`：種目選択、問題、結果の画面
- `style.css`：大きな文字とボタン、iPhone・iPad向けのレスポンシブ表示
- `game.js`：ランダム出題、数字入力、答え合わせ、結果集計
- `README.md`：この説明書

## Macで確認する

1. Finderでこのフォルダを開きます。
2. `index.html` をSafariやChromeで開きます（ダブルクリックで開けます）。
3. 「たしざん」か「ひきざん」を選びます。
4. 大きな数字ボタンで入力し、「こたえる」を押します。10は「1」「0」の順に押してください。「けす」で入力を全部消せます。
5. 正解後に次へ進み、10問終了すると結果が表示されます。

インストールやビルドは不要です。インターネットに接続していなくても遊べます。

## iPhone・iPadで確認する

Macと端末を同じWi-Fiにつなぎ、このフォルダでターミナルから次を実行します（Python 3がある場合）。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Macの「システム設定 → Wi-Fi → 接続先の詳細 → TCP/IP」でIPアドレスを確認し、iPhone・iPadのSafariで `http://MacのIPアドレス:8000` を開きます。例：`http://192.168.1.20:8000`。Mac自身では `http://localhost:8000` から確認できます。サーバーの停止はターミナルでControl+Cです。ローカル配信用のサーバーで、外部サービスは使いません。

## 問題と採点

- 使う数字は0〜10。たし算は答えも10以内、ひき算は答えが0以上になります。
- 1回10問。同じ式を重複させず、ランダムに選びます。
- 間違えたときは「もういちど！」と表示し、同じ問題に再挑戦できます。次の数字入力で前の答えを置き換えます。
- 結果の「10もんちゅう ○もん せいかい！」は、最初の回答で正解した問題の数です。再挑戦して正解した問題はこの数に含めません。
- 「もういちど！」は同じ種目で、新しい10問を始めます。
- 時間制限はありません。各問題の成績は保存・送信しません。星の合計、最後のチャレンジ達成日、連続日数、音の設定だけをこのブラウザに保存します。

## 確認するポイント

両方の種目、10の入力、0の入力、入力の消去、間違えた後の再挑戦、10問後の正解数、もう一度遊ぶ操作を確認してください。iPhone・iPadでは縦向きと横向きでボタンが押せることも確認できます。

## 毎日遊べる機能

- 1回10問、3〜5分が目安です。時間制限はなく、何回でも遊べます。
- その日の初回クリアで「きょうのチャレンジ クリア！」。日付は端末の現地時刻で、10問を終えた日を使います。
- 最初の回答で8〜10問正解なら星3個、5〜7問なら2個、0〜4問でも1個。同じ日の再プレイでも星を獲得できます。
- 星5個でひよこ、10個でうさぎ、20個でパンダ、30個でライオン、50個でおうかんが仲間になります。星は消費しません。
- 前日にクリアしていれば連続日数が増えます。同日中は増えず、間が空いても星と仲間は残ります。
- 毎回のクリアで短い星・紙吹雪・キャラクターの演出。全問正解の特別表示も残しています。動きを減らす設定ではアニメーションを抑えます。
- 音は初期OFF。ホームの「おと ON / OFF」で切り替えます。Web Audio APIで生成し、外部ファイルは使いません。
- ホーム下部の「せってい」から確認画面を経て進捗をリセットできます。音設定と他サイトのデータは消しません。

## 保存について

`localStorage` の `kids-math-game.progress.v1` に保存します。名前・個人情報は保存しません。同じブラウザ・同じサイトで続きが遊べます。サイトデータを削除すると消え、別端末・別URLには同期されません。ファイルを直接開いた場合の保存はブラウザ依存のため、継続利用にはローカルHTTP配信かGitHub Pagesを使ってください。保存できない環境では案内を表示し、そのページを閉じるまで遊べます。

## GitHub Pages

ビルド不要です。ルートの `index.html` と同じ場所に `style.css` と `game.js` を置く静的サイトとして配信できます。すべて相対パスなのでリポジトリ配下のURLでも動きます。今回の変更ではpushやPagesの公開設定は行っていません。
