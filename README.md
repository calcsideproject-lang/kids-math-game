# わくわく さんすう

小学1年生向けの、10問ずつ遊べる計算ゲームです。HTML・CSS・JavaScriptだけで動作し、外部サービス、外部フォント、ライブラリ、データベースを使いません。

## 作成したファイル

- `index.html`：種目選択、問題、結果の画面
- `style.css`：大きな文字とボタン、iPhone・iPad向けのレスポンシブ表示
- `game.js`：ランダム出題、数字入力、答え合わせ、結果集計
- `README.md`：この説明書

## Macで確認する

1. Finderでこのフォルダを開きます。
2. `index.html` をSafariやChromeで開きます（ダブルクリックで開けます）。
3. 「たしざん」か「ひきざん」を選びます。
4. 大きな数字ボタンで入力し、「こたえる」を押します。10は「1」「0」の順に押してください。「けす」で入力を全部消せます。
5. 正解後に次へ進み、10問終了すると結果が表示されます。

インストールやビルドは不要です。インターネットに接続していなくても遊べます。

## iPhone・iPadで確認する

Macと端末を同じWi-Fiにつなぎ、このフォルダでターミナルから次を実行します（Python 3がある場合）。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Macの「システム設定 → Wi-Fi → 接続先の詳細 → TCP/IP」でIPアドレスを確認し、iPhone・iPadのSafariで `http://MacのIPアドレス:8000` を開きます。例：`http://192.168.1.20:8000`。Mac自身では `http://localhost:8000` から確認できます。サーバーの停止はターミナルでControl+Cです。ローカル配信用のサーバーで、外部サービスは使いません。

## 問題と採点

- 使う数字は0〜10。たし算は答えも10以内、ひき算は答えが0以上になります。
- 1回10問。同じ式を重複させず、ランダムに選びます。
- 間違えたときは「もういちど！」と表示し、同じ問題に再挑戦できます。次の数字入力で前の答えを置き換えます。
- 結果の「10もんちゅう ○もん せいかい！」は、最初の回答で正解した問題の数です。再挑戦して正解した問題はこの数に含めません。
- 「もういちどあそぶ」は同じ種目で、新しい10問を始めます。
- 時間制限はありません。成績の保存や送信も行いません。

## 確認するポイント

両方の種目、10の入力、0の入力、入力の消去、間違えた後の再挑戦、10問後の正解数、もう一度遊ぶ操作を確認してください。iPhone・iPadでは縦向きと横向きでボタンが押せることも確認できます。
