# わくわく さんすう

小学1年生向けの、10問ずつ遊べる計算ゲームです。HTML・CSS・JavaScriptだけで動作し、外部サービス、外部フォント、ライブラリ、データベースを使いません。

## 作成したファイル

- `index.html`：種目選択、問題、結果の画面
- `style.css`：大きな文字とボタン、iPhone・iPad向けのレスポンシブ表示
- `game.js`：ランダム出題、数字入力、答え合わせ、結果集計
- `learning.js`：回答時間・学習履歴・保護者レポート
- `drive.js`：さんすうドライブの操作・描画・進行
- `tests/`：独立したページで実行する自動チェック
- `README.md`：この説明書

## Macで確認する

1. Finderでこのフォルダを開きます。
2. `index.html` をSafariやChromeで開きます（ダブルクリックで開けます）。
3. 「さんすうのぼうけん」からレベルを選びます。
4. 大きな数字ボタンで入力し、「こたえる」を押します。10は「1」「0」の順に押してください。「けす」で入力を全部消せます。
5. 正解後に次へ進み、10問終了すると結果が表示されます。

インストールやビルドは不要です。インターネットに接続していなくても遊べます。

## iPhone・iPadで確認する

Macと端末を同じWi-Fiにつなぎ、このフォルダでターミナルから次を実行します（Python 3がある場合）。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Macの「システム設定 → Wi-Fi → 接続先の詳細 → TCP/IP」でIPアドレスを確認し、iPhone・iPadのSafariで `http://MacのIPアドレス:8000` を開きます。例：`http://192.168.1.20:8000`。Mac自身では `http://localhost:8000` から確認できます。サーバーの停止はターミナルでControl+Cです。ローカル配信用のサーバーで、外部サービスは使いません。

## 問題と採点

- レベル1〜2は0〜10、レベル3〜5は0〜20。たし算は答えも上限以内、ひき算は答えが0以上になります。
- 1回10問。同じ式を重複させず、ランダムに選びます。
- 間違えたときは「もういちど！」と表示し、同じ問題に再挑戦できます。次の数字入力で前の答えを置き換えます。
- 子どもの結果画面は前向きなメッセージと星を表示し、細かい成績は保護者向け設定にまとめています。星の判定と正解数は最初の回答で正解した問題を数えます。
- 「もういちど！」は同じレベルで、新しい10問を始めます。
- 時間制限はありません。記録はこのブラウザ内だけに保存し、送信しません。

## 確認するポイント

両方の種目、10の入力、0の入力、入力の消去、間違えた後の再挑戦、10問後の星と保護者向け正解数、もう一度遊ぶ操作を確認してください。iPhone・iPadでは縦向きと横向きでボタンが押せることも確認できます。

## 毎日遊べる機能

- 1回10問、3〜5分が目安です。時間制限はなく、何回でも遊べます。
- その日の初回クリアで「きょうのチャレンジ クリア！」。日付は端末の現地時刻で、10問を終えた日を使います。
- 最初の回答で8〜10問正解なら星3個、5〜7問なら2個、0〜4問でも1個。同じ日の再プレイでも星を獲得できます。
- 星5個でひよこ、10個でうさぎ、20個でパンダ、30個でライオン、50個でおうかんが仲間になります。星は消費しません。
- 前日にクリアしていれば連続日数が増えます。同日中は増えず、間が空いても星と仲間は残ります。
- 毎回のクリアで短い星・紙吹雪・キャラクターの演出。全問正解の特別表示も残しています。動きを減らす設定ではアニメーションを抑えます。
- 音は初期OFF。ホームの「おと ON / OFF」で切り替えます。Web Audio APIで生成し、外部ファイルは使いません。
- ホーム下部の「おうちの人へ」から保護者確認を経て確認画面を経て進捗をリセットできます。音設定・レベルのON/OFFと他サイトのデータは消しません。

## 保存について

`localStorage` の `kids-math-game.progress.v1` に保存します。名前・個人情報は保存しません。同じブラウザ・同じサイトで続きが遊べます。サイトデータを削除すると消え、別端末・別URLには同期されません。ファイルを直接開いた場合の保存はブラウザ依存のため、継続利用にはローカルHTTP配信かGitHub Pagesを使ってください。保存できない環境では案内を表示し、そのページを閉じるまで遊べます。

## GitHub Pages

ビルド不要です。ルートの `index.html` と同じ場所に `style.css`、`learning.js`、`drive.js`、`game.js` を置く静的サイトとして配信できます。すべて相対パスなのでリポジトリ配下のURLでも動きます。今回の変更ではpushやPagesの公開設定は行っていません。

## さんすうのぼうけん（第3段階）

| レベル | 内容 | 初期設定 |
| --- | --- | --- |
| 1 | 10までのたし算 | ON |
| 2 | 10までのひき算 | ON |
| 3 | 20までのたし算（繰り上がりを含む） | OFF |
| 4 | 20までのひき算（繰り下がりを含む） | OFF |
| 5 | 20までのミックス（各5問） | OFF |

保護者向け「せってい」で各レベルを個別にON/OFFにできます。クリアによる自動解放はありません。10問を最後まで解くと、初回正解数にかかわらずカードにクリアマークが付きます。すべてOFFにもできます。

### 学習記録と出題調整

- 遊んだ回数はゲーム開始時、解いた問題数と正解数は各問題の最初の回答時に記録します。途中でやめた回・問題も含みます。再回答や連打では二重加算しません。
- 最近の傾向には直近60問の計算分類と初回正誤だけを保存します。第3段階の分類履歴には式や回答を保存しません。第5段階では計算の式・最初の回答・回答日時・時間を追加保存します。氏名などの個人情報は保存しません。
- 分類はたし算・ひき算それぞれの「10以内」「20以内で繰り上がり／繰り下がりなし」「繰り上がり／繰り下がりあり」です。
- 間違いが2問以上ある分類から、選んだレベルで出せるものを最多順で1種類選び、10問中最大2問だけ優先します。残りはランダムで、同じ回の式は重複しません。以前の回の問題が偶然出ることはあります。
- 子どもには傾向や正答率を表示しません。保護者画面に集計を表示します。

### 旧データとの互換性

保存キーは `kids-math-game.progress.v1` のままです。旧形式の星・最終達成日・連続記録・音設定を引き継ぎ、新しい項目だけ初期値を補います。コレクションも星から再現されるため維持されます。旧版では記録していなかった学習回数や正解数は推測せず、今回から集計します。

リセットの確認後は星・連続記録・コレクション・レベルのクリア・学習統計と最近の傾向を消去します。遊べるレベルと音の設定は維持します。

## とけいチャレンジ（第4段階）

ホームから「とけいチャレンジ」を選びます。レベル1は「○じ ちょうど」、レベル2は「○じ はん」です。レベル2は初期OFFで、保護者設定からONにできます。時計はSVGで描画し、短く太い茶色の針が時、長く細い青色の針が分を示します。半の短針は数字の中間に進みます。

3つの選択肢を押して回答します。1回10問で時刻は重複しません。再挑戦でき、星・毎日のチャレンジ・連続記録・音・クリア演出を計算ゲームと共通で使います。時計を初めて10問クリアすると、星の数とは別に「とけいメダル」を獲得します。再プレイしてもメダルは重複しません。

既存の保存キーに `clock` を追加し、旧データの星・学習履歴などを維持します。時計の設定、クリアしたレベル、メダル、開始回数、初回回答数・初回正解数、ちょうど／半の初回誤答数を保存します。途中で中断した分も記録します。計算と時計の学習統計は別々で、保護者画面で確認できます。名前や回答した時刻は保存しません。確認付きリセットでは時計の記録とメダルも消去しますが、時計レベルのON/OFFは維持します。

`clockLevels` の分の配列と、時・分を扱う描画・出題関数を分離しています。将来の15分・45分などは今回有効化していません。外部画像・ライブラリ・通信は追加していません。

## おうちの人レポート（第5段階）

「おうちのひとへ」を通常のタップで開くと、掛け算の確認画面が表示されます。2〜9の数（積12以上）から毎回ランダムに1問出し、直前と同じ式は避けます。数字入力後、OKまたはEnterで回答し、正解した場合だけ設定に進めます。不正解時に答えは表示しません。設定とレポートの間では再確認せず、ホームに戻ると再度確認します。答えは保存・送信せず、数字キーボードと全角数字入力にも対応します。これは誤操作を減らす仕組みで、本人認証ではありません。設定内の「おうちの人レポート」から、全体・たし算・ひき算を切り替え、概要と折りたたみ式の問題履歴を確認できます。時計の記録は従来の専用欄に残ります。

### 回答時間と保存上限

- 計算問題の表示処理完了から、最初の「こたえる」までを計測。数字ボタンを押す時間も含みます。最初の不正解後に再回答しても、時間や正誤を上書きしません。
- 30秒以上、非表示・フォーカス喪失・ページ離脱があった問題、時計の異常が疑われる計測は時間を `null`（参考外）として扱い、平均から除外します。正誤と回答数は記録します。
- 出題数は表示時、正解・不正解は最初の回答時に増えます。途中で中断すると出題数と回答数は一致しないことがあります。
- 各式に累計出題数・初回正解数・初回不正解数・最終出題日時・直近8回答（正誤、入力値、日時、時間）を保存。最近の平均はこの履歴から計算します。
- 現在の範囲では式は最大462種類。日別集計は直近14日、各日の各式の末尾5回答までに制限します。日別の回答数・時間合計は別途保持するため、期間平均は履歴件数の制限で偏りません。保存容量を超えた場合は既存保存を削除せず、保存不可の案内を出します。

### 習熟度の目安

閾値は `learning.js` の `LEARNING` で変更できます。

- データ収集中：直近5回答中3回答未満。正答率が十分でも有効な回答時間が3件未満なら判定を保留。
- ◎ パッとできる：直近5回答の正答率80%以上で、最後の3回答がすべて初回正解・3秒以内。
- ○ できている：正答率80%以上で、有効な時間の平均が10秒以内。
- △ もう少し練習：正答率80%未満、または有効な時間の平均が10秒超。

学習の診断ではなく、操作時間も含めた観察の目安です。子どもには時間・習熟度・正答率を表示しません。初回に3秒以内で正解したときだけ「⚡ パッとできた！」と表示します。制限時間やカウントダウンはありません。星の数には回答速度を使いません。

### 7日間比較

端末の現地日付を使い、今日を含む7日間とその前の7日間を比較します。開始回数は開始日、回答は回答日の集計です。ミックスの開始回数は全体では1回、たし算・ひき算の個別表示ではそれぞれ1回と数えます。時計は含みません。

各期間10回答以上ある場合に正答率を比較し、平均時間はさらに各期間10件以上の有効時間がある場合に比較します。パッとできる種類数は、各期間に判定可能な問題がある場合だけ比較します。期間内の各式の直近5回答で判定するため、問題別一覧（期間を限定しない直近5回答）とは異なることがあります。出題内容の違いによる影響も表示します。旧版の履歴から日時・時間を推測して埋めることはしません。

### 自動復習

「もう少し練習」に該当する式と、同じ計算分類で各数の差の合計が2以内の式を、1回につき最大2問優先します。残り8問以上は通常のランダム出題で、定着した式も含みます。まだ問題別データがない場合は従来の計算分類による調整を使います。同じ回では式が重複せず、ミックスは各5問を維持します。

### 追加データと互換性・リセット

保存キーは変更せず `learning` を追加します。

- `learning.problems[演算:左の数:右の数]`：累計と直近8回答
- `learning.days[YYYY-MM-DD]`：開始回数、式ごとの回答数・正解数・有効時間合計・有効時間件数・直近5回答

旧データにこの項目がなければ空で補います。星、連続記録、レベル、分類履歴、時計の統計・メダルは引き継ぎます。個人情報入力や外部通信はありません。

「学習記録だけリセット」は、計算と時計の統計・分類履歴・新レポートを消し、星・仲間・メダル・連続記録・クリア状況・設定を残します。従来の「きろくをリセット」はこれらの進捗も消去し、音とレベルのON/OFFだけ残します。どちらも消す内容を確認してから実行します。

### 自動チェックの再実行

`python3 tests/build_check.py` で `/tmp/math-learning-check.html` を生成し、Chromeで開くとチェック結果が表示されます。テスト専用の保存キー `kids-math-game.test.progress.v1` を使い、普段遊んでいるデータを使いません。ヘッドレス検証では独立した一時Chromeプロファイルを使用してください。音はモックでON/OFF・生成処理を検証し、実際の聞こえ方は端末で確認してください。

## 🚗 さんすうドライブ（第6段階）

ホームの「さんすうドライブ」から、見た目の違う3台の車と、保護者がONにしている計算レベルを選びます。車による速度・難易度・星の違いはありません。初回はハンドルの練習画面を表示し、「じゅんび OK！」で開始します。

- ハンドルを指やマウスで左右へドラッグすると、角度に合わせて車が左右に移動します。離すと滑らかに中央へ戻ります。ハンドルにフォーカスを合わせ、左右矢印キーを押し続けても運転できます。
- 車は自動で前進。問題が現れると減速し、左右に分かれた道の答えを読み、正しい道へハンドルを切って進みます。答えの看板はボタンではありません。
- 中央では分岐手前で待ち続けられます。判定前に一度ハンドルを中央に戻す必要があり、前の回答方向を握り続けて次の問題を誤回答することを防ぎます。
- 誤答でも事故やゲームオーバーはありません。いったん離して同じ問題を選び直します。最初の回答だけを採点・記録します。
- 10問でゴールし、通常と同じ基準（初回正解8〜10問で星3個、5〜7問で2個、それ以下で1個）で星を獲得します。毎日のチャレンジ・連続記録・クリアマーク・音・演出も共通です。
- 出題は既存の自動復習を再利用し、最大2問優先・同一回の式の重複なし・ミックス各5問を維持します。
- 外部画像は使わず車・ハンドル・分岐をSVG、道路や背景をCSSで描画します。requestAnimationFrameは1本で管理し、画面を離れると停止、非表示時は一時停止します。動きを減らす設定でも操作・判定は有効です。

### 学習記録と保存

既存保存キーの `drive` に `plays`（開始回数）、`goals`（ゴール回数）、`explained`（説明済み）、`car`（選択車）を追加します。旧データには初期値を補い、星・時計・学習履歴を維持します。

ドライブの回答も計算の累計、直近履歴、日別集計へ反映します。回答履歴に `source: 'math' | 'drive'` を追加し、旧履歴は通常問題として扱います。時間は問題の表示から最初に分岐を選ぶまでで、運転操作・分岐までの移動時間を含みます。

通常の平均時間とドライブの平均時間は保護者レポートで別表示します。日別の `sum` / `t` は通常問題のみ、`driveSum` / `driveT` / `driveN` はドライブの有効時間合計・有効件数・回答数です。正誤と回数は両モードを含みますが、速度による習熟度は通常問題だけで判定します。ドライブしかない問題は、正答が多くても「データ収集中」とし、運転時間で「遅い」と判定しません。直近履歴の保存件数と14日間の上限は維持します。

「学習記録だけリセット」はドライブの開始・ゴール回数も消し、選択車・説明済み状態は残します。進捗全体のリセットではドライブの追加項目も初期化します。

ドライブのコードは `drive.js`、追加の自動チェックは `tests/drive.js` に分離しています。GitHub Pagesには `drive.js` も配置してください。テストの生成・実行方法は前節と同じです。

### 自由運転を楽しむテンポ

問題のない道路を6秒走ってから、問題・左右の答えが6秒かけて遠くから近づきます。接近中も運転でき、徐々に減速します。問題と答えが遠くに見え始めた段階から、ハンドルを左右へ十分に切った操作時点ですぐ判定します。中央なら時間制限なく待てます。正解後は回答の数字とガイドが消え、次も6秒の自由運転を確保します。

10問目の後は6秒の自由運転を楽しみ、続く5秒でゴールゲートが近づきます。自動前進でゲートを通過してから星と結果を表示します。動きを減らす設定では拡大や移動を抑え、同じ時間配分で遊べます。

`drive.js` 冒頭の定数（秒）で調整できます。

- `DRIVE_FREE_RUN_DURATION = 6`：最初と問題間の自由運転
- `DRIVE_APPROACH_DURATION = 6`：標識への接近
- `DRIVE_GOAL_FREE_DURATION = 6`：最後の自由運転
- `DRIVE_GOAL_APPROACH_DURATION = 5`：ゴールゲートへの接近

回答時間は、小さい標識が見え始めた時点から記録します。接近演出が終わる前の回答も保存し、接近終了時に計測をリセットしません。ドライブ時間は従来どおり通常問題の速度判定と分離します。自由運転を優先するため、1回の所要時間は回答の速さに応じて変わります。

回答後のテンポは、正解表示1秒（`DRIVE_SUCCESS_DURATION`）の間も走行を続け、通常速度へ滑らかに戻ります。左右へ十分に切った操作時点で、車の移動アニメーションを待たず判定します。不正解後は再挑戦用の待機タイマーを設けず、一度中央へ戻せばすぐ選び直せます。初回・再挑戦とも、回答前の待機タイマーはありません。正解表示が終わった後の自由運転は6秒です。


### 道路と景色の描画

道路はSVGの固定した台形1枚です。左右端は直線で、上が少し狭く下が少し広い形を全フェーズで維持します。道路の変形・分岐・合流アニメーションはありません。中央は常に普通のまっすぐな破線です。Y字ガイドは使用しません。問題は最大24px、回答は最大28pxとし、上部1/3に収まるコンパクトな表示にしています。回答は左右に数字だけを表示し、接近時の拡大は控えめにしています。正解後は問題・回答をすぐ非表示にします。不正解時は同じ問題をすぐ選び直せるよう表示を維持します。

問題と回答は接近時間に合わせて縮尺と縦位置を変え、遠くでは小さく中央寄り、手前では大きく左右に離れて表示します。木・花・草・家は道路外の左右に8個だけ配置し、初期位置に少しランダムさを加えます。白線と景色は共通の速度・移動量を使い、減速・加速時にも位置をリセットしません。動きを減らす設定では景色と白線のスクロールを止めます。

自動チェックには、全フェーズで道路形状が変わらず中央が舗装されていること、Y字の白線がなく、問題・回答が各画面幅で上部1/3に収まること、景色が道路外にあること、道路と景色の移動量が一致すること、加速が滑らかなことを追加しています。


### Phase 7：くり下がりの追跡と「3つのかず」

保護者の「せってい」でレベル6「3つのかず」をONにすると遊べます。初期状態はOFFです。1回10問、星・コレクション・今日のチャレンジは既存と共通です。

- **くり下がり**：引き算の一の位を比較し、引かれる数の一の位が小さければ `subtractionBorrowing: true` にします。14 − 8 は該当し、15 − 3 は該当しません。11〜18から一桁を引く問題も既存の20までの問題プールで扱います。古い問題キーからも分類を復元します。
- **3つのかず**：最初の数は1〜10、残りは1〜9、演算は＋と−だけ。左から順に計算し、途中・最終回答とも0〜20の問題だけ出します。`firstStep` と `secondStep` に式と答えを保持します。
- **ヒント**：最初のタップは最初の式を考える案内、2回目は途中の答えと次の式を表示します。最終回答は直接示しません。ヒント中も初回回答までの計測を続けます。再挑戦中のヒントも記録し、初回の正誤・回答時間は書き換えません。
- **保存**：既存の `kids-math-game.progress.v1` を継続使用。問題に `operationType`・くり下がり分類・正解・途中計算、回答履歴に `hintUsed` を追加します。回答・正誤・時間・プレイモードと直近8回の履歴、直近14日の日別集計は従来の仕組みを使用します。欠けているヒント情報は未使用として読み込み、星・連続記録・時計メダル・旧履歴を保持します。
- **習熟と適応出題**：直近の複数回答による既存判定を再利用します。「パッとできる」は直近3回の通常回答がヒントなしで速く正解していることも必要です。復習候補は最大2問だけ優先し、同じ分類・近い数の問題を選びます。3つの数では演算の順序と3個目の数も比較します。1ゲーム内に同じ式は重複させず、残りはランダムに出します。
- **保護者レポート**：「確認する計算」に「くり下がりのひき算」「3つのかず」を追加。最近7日間の問題数・正答率・平均回答時間・ヒント使用回数と、問題ごとの最近8回の履歴を確認できます。新しい分類の問題一覧は最後に出題した順です。くり下がりには独立したプレイがないため、回数欄は集計対象名を表示します。通常とドライブの時間を混ぜず、30秒以上・中断した時間を平均から除くルールも維持します。
- **ドライブ**：画面・操作は変更せず、従来の5レベルのみです。3つの数は共有の問題生成関数で扱えますが、今回は通常のぼうけんだけで遊べます。

追加テストは `tests/phase7.js`。既存の `python3 tests/build_check.py` に含まれ、テスト専用の保存キーで実行されます。全問題候補の途中計算・答え、ヒント、旧データの移行、レポート、10問クリアと星、画面幅320/390/768px、ドライブへの影響を確認します。

### Phase 8：🏝️ さんすうじま

算数で集めた星を使い、自分の好きな場所に花や建物を置く箱庭です。トップの「🎮 あそぶ」から開きます。島では算数問題を出さず、遊ばない日があっても景色は変わりません。

- **操作**：「しまに おくもの」で選択 →「これを おく！」→ 表示されたマスをタップ。選ぶだけでは星を使いません。「やめる」で配置モードを終了できます。キーボードでは矢印キーで選択マスを動かし、Enterで配置できます。
- **星**：既存の `stars` は累計獲得数として維持し、島で使っても減らしません。コレクションの解除条件も同じです。島に充てられる累計を `islandEarned` として既存の進捗データに追加し、旧データでは今までの星から補います。算数・時計・ドライブのクリア時に同数を加算します。使える星は `islandEarned − 島のspent` で算出し、再読み込みで補充されません。
- **自由配置**：同じ縦横比のSVG上に、0〜1の割合座標で保存します。海・道・画面外や、建物が重なる場所には置けません。花・木・家を含む全アイテムを複数置けます。初期の家と木は無料です。
- **価格・上限**：`island.js` の `ISLAND_ITEMS` に名前・種類・絵文字・価格・サイズ・複数配置可否をまとめています。価格は10〜200個、保存上限は `ISLAND_LIMIT = 240`。描画は固定のSVGと配置物だけで、常時アニメーションや配置物ごとのイベントリスナーは使いません。
- **保存**：配置データは別キー `kids-math-game.island.v1`。`version`、`spent`、`nextId`、`undoId`、`items` を保存します。各アイテムは `{id,type,x,y,cost}`。配置と使用した星を1回の `setItem` で同時保存し、失敗したらどちらも変更しません。読み取れない島データは空の島で上書きしません。
- **もどす**：直前の1個だけ取り消し、その配置時の星を戻します。取り消し後は `undoId` を消すため、連打や再読み込みでも同じ配置を二重に返還しません。次の配置後は、その新しい1個だけ戻せます。
- **既存機能との関係**：獲得済みのコレクションを「しまの なかまたち」に表示し、未獲得は「？」です。「ドライブに いく」は既存の車選択画面へ移動するだけです。学習履歴・回答時間・習熟・適応出題を島から変更しません。
- **リセット**：既存の進捗・学習リセットでは島を消しません。島用の獲得累計 `islandEarned` と消費記録を保持することで、使える星も維持します。従来の進捗リセットは、通常の累計星・コレクションなどをこれまでどおりリセットします。島自体のリセット機能は追加していません。
- **表示**：海・草地・短い道・最初の家と木をSVGで描画します。画面サイズが変わっても配置の比率は同じです。保存は端末・ブラウザ内で、端末間の自動同期はありません。配置時の軽いアニメーションは `prefers-reduced-motion` で抑制し、音は既存のON/OFF設定に従います。

追加ファイルは `island.js` と `tests/island.js`。GitHub Pagesには `island.js` も含めて配置してください。既存の `python3 tests/build_check.py` で島のテストも組み込まれます。進捗・島ともテスト専用キーを使用し、実際の保存データには触れません。


#### 配置マスへの変更

配置モード中だけ、6列×5行を基準にした薄い角丸のマスを表示します。初期の家・木・道を除いて、花の配置候補は最大20マスです。20個の花を同時に置けます。海・道・既存アイテムと重なる場所は候補から除くため、表示されるマス数は島と選択アイテムによって変わります。中央の点線カーソルは削除しました。配置・キャンセル後はマスを消し、配置成功時だけ短い選択反応を表示します。

新しい配置はマス中央に揃え、従来の `x/y` に `row/column`（0始まり）を追加保存します。旧配置は位置を動かさずに読み込み、重なり判定の対象にします。アイテムの価格・描画サイズは維持し、サイズに応じた距離判定とマスの占有判定を併用します。新しい観覧車・お城は2×2マスを予約し、4マスすべてが草地で空いている場合だけ候補にします。新しいグリッドの保存には `gridVersion: 2` を付け、旧グリッドは割合座標で位置を保持します。既存の配置を強制的に移動する変換はありません。


配置候補はアイテムの実寸で海・道・初期オブジェクトとの干渉を判定します。マスの四隅が海にかかるという理由だけでは除外せず、SVGマスクで表示を草地の輪郭に沿って切り抜きます。既存アイテムの上にもマスを描きません。狭い画面では島を横スクロールできるようにし、SVG幅を最低480pxに保ってマスの基準タップ領域を約56×44px以上にします。
